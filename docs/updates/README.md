# Weekly updates

One short file per week, `docs/updates/2026-10-20.md`, sent to the PI the day before the meeting. One page at most.

```markdown
# Update · week of 2026-10-20

## Done
- [what moved forward, with links to tables or figures in output/]

## Results worth discussing
- [the one or two things the meeting should look at]

## Problems
- [what is blocked and what would unblock it]

## Decisions needed from the PI
- [each with the options and your suggestion]

## Plan for next week
- [three items at most]
```
