# Research log

One file per person: `docs/log/<your-name>.md`. One entry per working session, **newest entry on top**. Five minutes at the end of each session.

Copy this block for each entry:

```markdown
## 2026-10-20 · [name]

**Did:** what you worked on, with the scripts or commits involved.
**Found:** results, surprises, anything that did not behave as expected.
**Decided:** choices you made and why (or that you are waiting for the PI to make).
**Next:** where to pick up next session.
**Questions for PI:** anything that needs their call.
```
